# SEO Strategy

- Unique localized routes under /en and /bn.
- Sitemap generated by src/app/sitemap.ts including all tools and locales.
- Robots.txt via src/app/robots.ts.
- Metadata per page where implemented; canonical/hreflang to be verified per route.
- Structured data (Schema.org) to be added/validated for tools and articles.
- Avoid duplicate/thin content; blog posts require unique value.
- Monitor broken links and duplicate metadata via admin SEO tools.

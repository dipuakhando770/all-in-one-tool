# SEO Content Strategy & People-First Quality Guidelines

**Target Domain:** `tools.nasirdigitalhub.com`  
**Reference Standard:** Google Helpful Content System & Search Quality Rater Guidelines (E-E-A-T)

---

## 1. Core Principles: People-First vs Search Engine-First
1. **Never generate robotic keyword-stuffed fluff:** Each tool page's content must serve the user immediately by offering clear, step-by-step instructions and technical reality.
2. **Explain real limitations honestly:** If a tool only supports files up to 50MB in-browser, clearly state it. Users value accuracy over exaggerated claims.
3. **Dual-Language Authenticity:** Bengali content must be written in natural, fluent Bengali phrasing (e.g., "ফাইল সাইজ কমানোর সহজ উপায়" instead of literal word-for-word machine translation).

---

## 2. Universal Tool Page Content Architecture
Every high-value tool template must contain the following structural sections:
1. **Interactive Tool Workspace (Above the Fold):** Immediate utility access without scrolling past walls of text.
2. **How It Works (Step-by-Step Instructions):** 3 to 4 sequential steps explaining input, configuration, and download.
3. **Key Features & Browser Security:** Highlighting in-memory processing, zero-upload architecture, and client privacy.
4. **Use Cases & Examples:** Real-world developer/student/office worker scenarios.
5. **Frequently Asked Questions (FAQ):** 3 to 5 genuine user questions formatted cleanly for schema ingestion.

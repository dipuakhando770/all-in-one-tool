## 2. On-Page Search Central Compliance Guidelines
1. **Title Length:** 50 - 60 characters, brand suffix `| NASIR TOOLS`.
2. **Meta Description:** 140 - 155 characters, concise value proposition with primary and secondary keyword.
3. **Structured Data:** `WebApplication` schema on every tool route, plus `BreadcrumbList`.
4. **Hreflang Tags:** Explicit `<link rel="alternate" hreflang="en" ...>` and `hreflang="bn"` with self-referential canonical tags.

# PDF Enhancement Report

## Implemented
- pdf-to-image (pdfjs-dist, single page render to PNG).
- pdf-merger, pdf-split-to-zip, pdf-rotator, pdf-page-extractor, pdf-page-deleter, image-to-pdf, pdf-add-page-numbers, pdf-page-count, pdf-metadata-viewer.

## Not implemented
- Batch PDF-to-image export (single page only).
- PDF compression (pdf-lib reserialization not meaningful compression).
- PDF page thumbnails/preview grid.

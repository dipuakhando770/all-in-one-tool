## 2. Skill Categories, Activation Criteria & OpenCode Usage

### A. UI/UX & Design Systems
- **Skills:** `ui-ux-pro-max`, `web-design-guidelines`, `ui-design`, `shadcn`, `tailwind`.
- **When to activate:**
  - Designing or refactoring homepage, tool layout, header, footer, or command palette.
  - Ensuring typography, contrast ratios, spacing tokens, responsive breakpoints, and dark/light mode parity.
  - Adding loading skeletons, toasts, and empty states.
- **Authoritative Source:** `ui-ux-pro-max` is primary for the visual hierarchy, color palette, and micro-interactions; `web-design-guidelines` governs layout ergonomics and accessibility compliance.

### B. React, Next.js Architecture & Performance
- **Skills:** `vercel-react-best-practices`, `nextjs`, `react`, `vercel-composition-patterns`, `next-bundle-optimizer`, `next-cache-components-optimizer`, `next-dev-loop`.
- **When to activate:**
  - Structuring App Router layouts, templates, and server vs client component splits.
  - Optimizing dynamic imports, bundle size reduction, code splitting, and memoization.
  - Data fetching, state management, and Cloudflare OpenNext edge runtime considerations.
- **Authoritative Source:** `vercel-react-best-practices` and official Next.js skills govern Next.js 15/16 App Router code patterns.

### C. Web Quality, SEO & Core Web Vitals
- **Skills:** `web-quality-audit`, `seo`, `performance`, `core-web-vitals`, `accessibility`, `best-practices`.
- **When to activate:**
  - Inspecting and refining metadata, JSON-LD structured data, sitemap generation, and canonical URLs.
  - Auditing LCP, FID/INP, and CLS scores.
  - Ensuring WCAG 2.1 AA keyboard navigation, ARIA attributes, and screen-reader usability.
- **Authoritative Source:** `web-quality-audit` & `seo` from Addy Osmani's suite.

### D. Quality Assurance, Validation & Forms
- **Skills:** `zod`, `react-hook-form`, `vitest`, `playwright`, `msw`, `tdd`.
- **When to activate:**
  - Building client-side input validation and error states for conversion/utility tools.
  - Writing unit, component, or E2E tests for tool registries, search algorithms, and file processors.

## 3. Handling Overlapping Guidance

Where skills offer duplicate or slightly differing advice:
1. **App Router & React:** Follow `vercel-react-best-practices` and Next.js official skills over generic React guidelines.
2. **Styling & Components:** Prefer Tailwind CSS v4 and existing design tokens in `globals.css` with guidance from `ui-ux-pro-max` and `web-design-guidelines`.
3. **Audit & Verification:** Use `web-quality-audit` standards as the ground truth before reporting deployment readiness.
